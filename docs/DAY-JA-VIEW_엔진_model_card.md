# 모델 카드 — 과거 유사사례 매칭 엔진 v1

> 명세 산출물 #9. 2026-08-13.

## 모델
- **이름**: `match-engine-v1` = 검색 `m_txt`(K01 원인문 char 2-3gram TF-IDF cosine) · K=20 · outcome `leader_ew_v1`(당시 주도주 동일가중) · 클러스터 dedup · PIT 집계.
- **코드**: `backend/app/engine/{retrievers,baseline0,serve,outcomes,replay}.py` · CLI `engine-match`.
- **선택 근거**: 봉인된 선택정책 — 게이트1 관련성 nDCG@5 0.857(B0 대비 +0.195, 95%CI 0 배제)·무관 1%, 게이트2 예측력 동률, 동률군 내 최단순.

## 하는 일 / 안 하는 일
- **한다**: 같은 테마의 과거 사건 중 원인문이 구조적으로 비슷한 사건 검색, 공유 토큰 근거 태그, 그 사건들의 **관측된** D+1/5/20 결과 요약(상승 n/유효 n·중앙값), 표본 경고.
- **안 한다**: 방향·수익 예측(검증 결과 이웃 상승비율의 T+1 신호 ≈ 0), 수치 유사도·확률 표시, 매수·매도 추천.

## 데이터 범위
- 사건: 인포스탁 39,643건(2005~2026), **엄격 outcome은 2022~2026 주도주 보유 16,575건**.
- 가격: 키움 수정종가 7.2M행(상폐 등 466종목 무가격 — 생존편향 잔존, lead 기준 86종목).
- 후보는 query와 같은 테마·과거·다른 중복클러스터·leader outcome 보유만.

## 알려진 한계 (사용 금지 조건 포함)
1. **T+1 방향 예측에 사용 금지** — 기저율 이하. 통계는 "관측된 과거"로만 표기.
2. 이웃 분위수는 실제 분산보다 좁음(50%구간 실포함 34~46%) — **예측구간으로 표시 금지**.
3. 어휘 기반 한계: 동의어·신규 표현(임베딩 부재), 문구가 비슷하면 구조가 달라도 상위 가능.
4. 관련성 라벨 1인(Claude) — 2인 검수 전이며 밴드(매우비슷함 등) 미보정 → similarity_band 미노출.
5. 초과수익 미계산(지수 부재) — 시장 국면 효과 미분리.
6. pre-2022 사건은 후보에서 제외됨(주도주 기록 부재) — 오래된 선례는 안 나옴.
7. 장중 사용 부적합(일봉·장마감 기준 설계).
